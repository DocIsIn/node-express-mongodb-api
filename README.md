# Lab 2 - RESTful API with Node.js, Express, and MongoDB

This project was built for Lab 2 of the software development course. It demonstrates a basic RESTful API using Node.js, Express.js, and MongoDB, with Swagger for documentation and Postman for testing.

Built with Node.js and Express. Connected to a local MongoDB database. API endpoints to GET and POST items. Swagger UI for interactive documentation. And was Postman used for request testing
